# InverseScanlineUtility
Inverse Scanline Utility is used to completely mitigate tone based scanlines across all monitors. 

This is done by simulating scanlines and overlaying them on screen. After adjusting the period (distance between scanlines), amplitude (intensity/brightness of the scanlines) and phase (where the scanlines are positioned on the screen), so that the simulated scanlines are superimposed over the true scanlines, they are effectively cancelled out, creating a smoother image.
