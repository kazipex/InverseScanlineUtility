# InverseScanlineUtility
The Inverse Scanline Utility is used to completely mitigate tone based scanlines across all monitors. 

This is done by simulating scanlines and overlaying them on screen. After selecting the offending tones, adjusting the period (distance between scanlines), amplitude (intensity/brightness of the scanlines) and phase (where the scanlines are positioned on the screen), so that the simulated scanlines are in phase with the true scanlines, their effects are negated, creating a cleaner and more accurate image.
